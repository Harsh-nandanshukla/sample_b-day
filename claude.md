# Birthday Surprise Website

Create a romantic, interactive birthday website using ONLY:

- HTML
- CSS
- Vanilla JavaScript

No frameworks.
No npm.
No React.
No external libraries unless absolutely necessary.

Theme:
- Soft pastel pink aesthetic
- Background should be a pink gradient that transitions into a warm cream/buff color at the center.
- Glassmorphism UI.
- Premium romantic appearance.
- Floating hearts.
- Elegant animations.
- Mobile-first responsive design.
- No dark theme.

Features:

1. Floating Background

- 20–30 photographs should continuously float around the page.
- Photos should have different sizes, speeds, slight rotations and smooth movement.
- Around 120 floating hearts should continuously animate around the photos.
- Hearts should use multiple shades of pink.
- Hearts should have random opacity, size and animation speed.
- Hearts and photos should never distract from the center card.
2. Header

Large glowing magenta heading:

🎂 Happy Birthday Baby ❤️

Below it show the subtitle:

"Every picture floating around you reminds me how lucky I am to have you."
3. Beautiful center card.
4. "Do you love me?" section.
5. Balloon YES and NO buttons.
6. YES:
   - Balloon pop animation
   - Confetti
   - Romantic music
   - Random compliment
   - Next compliment button
7. NO:
   - Escapes cursor
   - Shrinks every escape
   - Changes text:
     Are you sure?
     Really?
     Think again...
     Wrong answer.
     I know the answer already.
   - Finally disappears into hearts.
8. After 10 compliments:
   Show "Open Your Birthday Gift".
9. Final birthday message.
10. Ending animation:
    Photos slowly form a large heart.
11. Responsive on mobile and tablet.
12. Keep the website smooth and elegant.


# Development Rules

- Read this file before every implementation.
- Never rewrite completed files unless requested.
- Implement one feature at a time.
- Preserve responsive behavior.
- Keep JavaScript modular and well commented.
- Do not introduce unnecessary libraries.
- Keep animations smooth (target 60 FPS where practical).
- Do not remove existing functionality while adding new features.

# Code Quality

- Clean, modular and well-commented code.
- Separate HTML, CSS and JavaScript responsibilities.
- Optimize animations and DOM manipulation.
- Ensure compatibility with desktop, tablet and mobile browsers.
- Use semantic HTML and meaningful class names.
